묑류계 — 디시인사이드 정류기 / Windows 실행용

1. 실행형은 받은 '묑류계-버전.exe'를 더블클릭하세요(예: 묑류계-0.3.6.exe). 설치형은 설치 후 시작 메뉴에서 '묑류계'를 실행하세요.
2. 상단 공통 영역에서 본인의 디시 아이디와 비밀번호로 로그인하세요. '이 PC에 계정 저장'이 켜져 있으면 성공한 계정을 저장합니다.
   비밀번호는 Windows 자격 증명 관리자에만 저장합니다. '다음 실행 시 자동 로그인'을 끄면 수동 로그인합니다.
   저장된 계정을 고르고 비밀번호 칸을 비워 두면 저장된 비밀번호로 자동 로그인하며, 비밀번호를 직접 입력하면 입력값으로 로그인합니다.
   여러 계정은 '다른 계정 / 추가'로 등록하고 아이디 목록에서 선택합니다. 로그아웃하면 자동 로그인이 꺼집니다.
   보안문자가 나오면 직접 입력하세요. 다른 사용자의 계정이나 로그인 정보는 포함되어 있지 않습니다.
   자동 로그인 실패는 반복하지 않습니다. 저장 비밀번호가 틀리면 비밀번호를 직접 입력해 로그인하면 갱신됩니다.
3. 상단에서 갤러리를 선택(직접 입력해 조회한 갤러리 ID는 다음 실행 때도 목록에 남음)하고 관리 권한을 확인한 뒤, '목록 정리' 탭의 '최신 1페이지'·'1~3페이지'·'1~5페이지' 버튼으로 바로 조회하세요. 다른 범위는 '직접' 칸에 적고 '조회'(F5)를 누릅니다(최신 1페이지 Ctrl+R).
   수동 삭제는 '비회원 일반글 선택' 또는 '일반글 전체 선택 (회원 포함)'과 개별 선택(체크칸 클릭 또는 Space)을 지원합니다.
   표의 주황 바탕은 비회원, 파란 바탕은 개념글, 회색 글씨는 판별 불가 글입니다.
   일반글과 개념글이 섞여 선택되면 삭제·해제 버튼이 잠기며, 아래쪽 '일반글만 남기기'·'개념글만 남기기' 버튼으로 바로 정리할 수 있습니다.
   '선택 삭제'(표에서 Delete 키도 같음)를 누르면 표 아래 인라인 확인 카드가 열립니다. 대상과 계정을 확인한 뒤 '위 글 실제 삭제'를 누르면 실행되며, 끝나면 방금 본 페이지를 자동으로 다시 조회해 남은 글을 표에 보여 줍니다. 본문·이미지 백업과 삭제 복구 기능은 없습니다.
4. 상단 '방어 켜기'를 누르면 어느 탭에서든 방어를 시작하고, 같은 자리 '방어 끄기'로 멈춥니다. 옆 글씨로 방어 상태가 항상 보입니다.
   감시 페이지 수와 회원 옵션은 '자동 방어' 탭에서 정하며, 탭의 '방어 시작'으로도 실행할 수 있습니다. 탭을 열어 보는 것만으로는 다른 기능이 잠기지 않고 실제 방어 시작 시에만 잠깁니다.
   '회원 깡계도 제거 대상에 포함'은 기본 해제이며, 체크하면 신규 딱지가 확인된 회원도 대상에 포함합니다.
   일반 회원과 판별 불가 회원은 제외합니다. 실행 중에는 옵션을 바꿀 수 없습니다.
   방어 시작 시 최신 1페이지의 글 번호를 기준으로 잡으며, 그 조회에서는 삭제하지 않습니다.
   기준보다 새로운 비회원 일반글·개념글을 최신 목록에서 삭제합니다. 기존 글과 공지는 항상 제외하며 회원은 위 옵션에 따릅니다.
   기준을 확인하지 못하면 삭제 없이 중지합니다. 재시작하면 최신 기준을 다시 잡습니다.
5. 방어는 최신 목록을 다시 읽어 처리합니다. 같은 글은 요청 중과 응답 후 2초간 제외합니다.
   이후 새 목록에 남아 있으면 다시 처리하며, 응답 유실만으로 중지하지 않습니다.
   권한·한도·요청 제한·명시적인 서버 거부가 발생하면 중지합니다.
   방어는 현재 선택해 로그인한 계정을 사용합니다. 한도 도달 후 다른 계정으로 자동 전환은 아직 지원하지 않습니다.
   방어 조회는 수동 페이지와 별개입니다. 최신 1페이지부터 감시할 페이지 수를 1~5개 중 선택합니다(기본 1개).
   페이지 수가 많으면 조회 시간이 늘어납니다. 비회원 개념글은 1개씩 별도 삭제 요청을 보냅니다.
6. 방어 중지·창 닫기는 진행 중인 통신 종료까지 기다립니다. 이미 보낸 요청은 취소되지 않을 수 있습니다.
   방어 건별 기록은 저장하지 않습니다. 요청 수락은 글별 삭제 완료 확인과 다릅니다.
   수동 작업은 수락·거부·미확인·미전송을 구분합니다. 미확인 결과는 다시 조회해 확인하세요.
7. 끌올은 '끌올' 탭에서 사용하며, 메인 창에 로그인한 계정을 그대로 씁니다. 오른쪽 위 '단일 글 끌올'·'여러 글 순환 끌올'로 방식을 고릅니다.
   '목록 정리' 탭에서 글 1~20개를 선택하고 '끌올로 보내기'를 누르면 끌올 탭의 주소 칸에 자동으로 채워집니다(요청은 바로 보내지 않음).
   끌올 탭을 보는 것만으로는 메인 창이 잠기지 않으며, '1회 시험'('전체 1회씩') 또는 '반복 시작'으로 실제 끌올이 도는 동안만 다른 작업이 잠깁니다.
8. 개념글 해제는 '개념글만 선택' → '선택 개념글 해제' → 표 아래 인라인 확인 카드에서 대상 확인 후 '위 글 개념글 해제'를 누르세요.
   글은 남고 개념글 등록만 해제되며, 완료 후 방금 본 페이지를 자동으로 다시 조회해 남은 목록을 보여 줍니다.
   추천 컷·보안문자 설정 변경과 개념글 재등록은 아직 지원하지 않습니다.

업데이트: 실행 중인 묑류계의 작업을 마치고 창을 닫은 뒤 실행형 EXE를 새 파일로 교체하세요.
설치형은 같은 순서로 창을 닫고 새 설치 파일을 실행하세요.
프로그램이 안 열리면 묑류계를 닫고 배포 파일을 다시 받아 실행하세요. 설치형은 재설치하세요.
설치·제거는 기존 사용자 자료를 지우지 않습니다.
내용 없는 성능 진단은 AppData\Local\Rectifier\diagnostics에 크기를 제한해 저장합니다.

현재 배포 파일은 코드 서명되지 않은 시험판입니다. 다른 PC의 실행 환경은 별도 확인이 필요합니다.
Python을 따로 설치하지 않아도 실행됩니다. 자동 업데이트는 제공하지 않습니다.
실행형은 PyInstaller로 제작했고 시작할 때 내부 파일을 임시 폴더에 풉니다.
설치형은 Inno Setup도 사용합니다. 포함 라이브러리 고지는 실행형의 내부 licenses 또는 설치형의 _internal\licenses에 있습니다.
